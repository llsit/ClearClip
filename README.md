# ClearClip — TikTok Downloader

เว็บแอปภาษาไทยสำหรับรันบนเครื่อง Windows ดาวน์โหลดวิดีโอ TikTok เป็น MP4 พร้อมเสียง โดยใช้ Flask และ yt-dlp

## ขึ้นเว็บ Render

เตรียม `render.yaml` และ Gunicorn แล้ว ดูขั้นตอนและข้อจำกัดใน [DEPLOY.md](DEPLOY.md) ยังต้องเชื่อมบัญชีและ deploy ก่อนจึงจะได้ URL ออนไลน์

## เริ่มใช้งาน

1. ติดตั้ง Python 3.10 ขึ้นไป และเปิดตัวเลือก Add Python to PATH
2. ดับเบิลคลิก `start.bat` (ครั้งแรกต้องใช้อินเทอร์เน็ตติดตั้ง dependencies)
3. เปิด http://127.0.0.1:8787 ในเบราว์เซอร์
4. วางลิงก์วิดีโอ กดดาวน์โหลด รอจนพร้อม แล้วกด **บันทึกไฟล์ MP4**

ปิดด้วย Ctrl+C ในหน้าต่างเซิร์ฟเวอร์ หากพอร์ต 8787 ถูกใช้อยู่ ให้ปิดแอปเดิมก่อน

### รันด้วยคำสั่ง

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py
```

## การเลือกคุณภาพและลายน้ำ

เมื่อดึงข้อมูลหรือดาวน์โหลดล้มเหลวจาก yt-dlp/เครือข่าย ระบบลองใหม่อัตโนมัติรวมสูงสุด 3 ครั้ง โดยรอ 2 และ 4 วินาที แต่ละครั้งล้างไฟล์ที่ไม่สมบูรณ์และดึงข้อมูลวิดีโอใหม่ หน้าเว็บแสดงสถานะการลองใหม่ในรายการเดิม กรณีลิงก์ไม่ถูกต้อง ไม่มี format ที่รองรับ หรือไฟล์เกินขนาด จะหยุดพร้อมแจ้งสาเหตุ

- รับลิงก์วิดีโอเต็ม, vm.tiktok.com, vt.tiktok.com และ /t/ ของ TikTok
- เลือกไฟล์ MP4 ที่มีภาพและเสียง ตัด format ที่ระบุ watermarked, unplayable และ download variant ออก
- เรียงตามจำนวนพิกเซล ตามด้วย bitrate ขนาดไฟล์ และ fps โดยไม่แปลงหรือบีบอัดซ้ำ
- ไม่ใช่เครื่องมือลบลายน้ำด้วย AI และไม่อัปสเกล: ลายน้ำที่ผู้สร้างฝังในภาพยังอยู่ได้ Metadata ของต้นทางไม่ได้รับประกันว่าภาพไม่มีลายน้ำทุกเฟรม
- หากไม่พบ format ที่ผ่านเงื่อนไข จะแจ้งข้อผิดพลาด ไม่มีการสลับไปดาวน์โหลดไฟล์ที่ระบุว่ามีลายน้ำ
- รองรับเฉพาะวิดีโอสาธารณะที่ต้นทางเปิดให้เข้าถึง ไม่รองรับโพสต์รูปภาพ ไลฟ์ หรือวิดีโอที่ต้องล็อกอิน
- การเข้าถึงขึ้นกับ TikTok ภูมิภาค และเครือข่าย จึงไม่รับประกันทุกลิงก์หรือความละเอียด 1080p/4K

## การเก็บไฟล์

ไฟล์ชั่วคราวอยู่ใน `downloads/` ภายในโปรเจกต์ เก็บได้ 20 รายการ งานพร้อมกัน 2 งาน และรอคิวได้อีก 2 งาน จำกัด 128 MB ต่อไฟล์ งบพื้นที่รวม 512 MB รายการที่จบเกินหนึ่งชั่วโมงจะถูกล้างอัตโนมัติทุกนาที ไฟล์ที่บันทึกผ่านเบราว์เซอร์จะยังอยู่ในโฟลเดอร์ดาวน์โหลดของคุณ

แอปผูกกับ 127.0.0.1 สำหรับใช้บนเครื่องเดียวเท่านั้น ไม่ควรนำ Flask development server นี้ไปเปิดสาธารณะโดยตรง

## เมื่อ TikTok เปลี่ยนระบบ

```powershell
.venv\Scripts\python -m pip install -U yt-dlp
```

จากนั้นปิดและเปิดแอปใหม่ หากยังไม่ได้ ให้ลองวิดีโอสาธารณะอื่น ไม่มีการข้าม CAPTCHA หรือการจำกัดการเข้าถึง

## ทดสอบ

```powershell
.venv\Scripts\python -m pip install pytest
.venv\Scripts\python -m pytest -q
```

Tests ใช้ข้อมูลจำลอง ตรวจสอบการเลือก format การตรวจลิงก์ API และการส่งไฟล์ ไม่ใช้แทนการทดสอบดาวน์โหลดจาก TikTok จริง

## โครงสร้าง

`app.py` — API, คิว, ตัวเลือก format และการดาวน์โหลด

`static/` — หน้าเว็บภาษาไทย CSS และ JavaScript

`tests/` — การทดสอบอัตโนมัติ

เอกสารอ้างอิง: https://github.com/yt-dlp/yt-dlp และ https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/extractor/tiktok.py

ใช้กับวิดีโอของคุณหรือที่คุณได้รับอนุญาตให้ดาวน์โหลด
